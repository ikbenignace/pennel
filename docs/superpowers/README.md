# Historical implementation plans

This directory preserves dated design plans and handoffs from earlier Pennel implementations. Commands, paths and proposed decisions describe their recorded revision; they are not current project instructions.

The legacy SwiftUI iOS and macOS shells and their build/capture/release tools were retired under [cleanup #75](https://github.com/pennel-app/pennel/issues/75). Their [iOS source](https://github.com/pennel-app/pennel/tree/e6f02b2cd178b541dcbfcdb46125336c762dbf07/apps/ios), [Mac source](https://github.com/pennel-app/pennel/tree/e6f02b2cd178b541dcbfcdb46125336c762dbf07/apps/macos) and [scripts](https://github.com/pennel-app/pennel/tree/e6f02b2cd178b541dcbfcdb46125336c762dbf07/scripts) remain available at the pre-retirement base. The original visual reference is commit `91775c1`.

Use the current [contributor guide](../../CONTRIBUTING.md), [desktop guide](../desktop.md), [mobile guide](../mobile.md) and [roadmap workflow](../desktop-roadmap.md#agent-workflow). Existing device, signing, upgrade, keyboard, Cloud and store acceptance requirements remain open until separately verified.
