**Say it. Full stop.** Pennel is a tiny macOS app for everything you say: hold a key to dictate polished text into any app, and record meetings into transcripts and notes that stay on your Mac.

- **Dictate anywhere.** Hold `fn`, speak, let go: cleaned-up text appears where your cursor is. Fillers, false starts and self-corrections are removed; style adapts per app (casual in Slack, formal in Mail, literal in your terminal). Double-tap for hands-free.
- **Commands.** Add `⇧` while speaking: rewrite the selected text ("make this more formal", "translate to English") or write something new ("draft a short mail saying I'm late").
- **Meetings.** Records your microphone and the call's system audio (Teams, Meet, Zoom, …) as separate tracks, detects calls and asks to record, transcribes in chunks, splits speakers and lets you name them, then writes notes or a summary from your own templates. Search everything, ask questions with cited answers, export to Notion/Slack/Mail.
- **Private first.** Run speech models locally (Whisper, Parakeet and more, via Metal) or bring your own provider (OpenAI, Groq, OpenRouter, Mistral, Ollama, LM Studio, any OpenAI-compatible endpoint). Meetings are plain Markdown files in a folder you choose. No account, no telemetry. Keys live in the Keychain.
- **Light.** ~14 MB app, ~16 MB memory at rest. Rust core, native Swift UI.

Requires macOS 14.4+ on Apple Silicon.

## Build

Prerequisites: Xcode (Swift 6), Rust with the `aarch64-apple-darwin` target, CMake (`brew install cmake`), and `librsvg` only if you change the icons.

```sh
make core   # Rust core + Swift bindings + XCFramework
make test   # Rust and Swift tests
make app    # build/Pennel.app
make run    # build and open
```

`apps/macos/Frameworks/` and `apps/macos/Sources/PennelCore/` are generated by `make core`.

### Signing during development

Ad-hoc signed builds make macOS forget permissions (microphone, accessibility) after every build. Create a local signing certificate once (asks for your password):

```sh
scripts/create-dev-cert.sh
make app
```

Releases are signed with a Developer ID and notarized; see [docs/releasing.md](docs/releasing.md).

## First run

1. Allow **Microphone** and **Accessibility** (for the hotkey and for pasting).
2. Pick a provider in **Settings → Providers**, or download a local model under **Local**.
3. Set **System Settings → Keyboard → Press 🌐 key to** *Do Nothing*, otherwise `fn` opens the emoji picker.

Logs for troubleshooting: menu bar → **Logboek openen** (`~/Library/Logs/Pennel/pennel.log`). It records timings, lengths and errors, never what you said.

## Local models

Local speech recognition runs through [transcribe.cpp](https://github.com/handy-computer/transcribe.cpp). The model list comes from the bundled [`@handy-computer/models`](https://github.com/handy-computer/models) catalog (`core/src/catalog.json`) with benchmarked speed, accuracy per language and supported languages. Update it with `scripts/update-catalog.sh <version>`.

## Layout

- `core/` — Rust core (`pennel-core`): providers, cleanup, history, meetings, search index, local engine; exposed to Swift with UniFFI
- `apps/macos/` — Swift package: `PennelKit` (pure, tested logic) and `Pennel` (the app)
- `assets/brand/` — logo, icons and brand guide
- `scripts/` — build, bundle, icon and release scripts
